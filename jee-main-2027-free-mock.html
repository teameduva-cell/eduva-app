🧪 Original Solved Questions (JEE Main Pattern)

Q1. (Physics) Ek particle ka position vector r = (3t² − 2t) î + (4t³) ĵ meter mein hai। t = 2 s par acceleration ka magnitude kya hoga?
Solution: v = dr/dt = (6t−2)î + 12t²ĵ; a = dv/dt = 6î + 24tĵ. t=2: a = 6î + 48ĵ → |a| = √(36+2304) = √2340 ≈ 48.4 m/s² ✅
Q2. (Chemistry) 25°C par ek reaction ka rate constant k = 2.5 × 10⁻³ s⁻¹ hai। Reaction ki order kya hai?
Solution: Unit s⁻¹ (time⁻¹) → first order reaction. Answer: First order ✅ (t₁/₂ = 0.693/k = 277 s ≈ 4.6 min)
Q3. (Maths) ∫₀^π x·sinx·cos²x dx का मान ज्ञात कीजिए।
Solution: Property: ∫₀^π x·f(sinx)dx = (π/2)∫₀^π f(sinx)dx. So I = (π/2)∫₀^π sinx·cos²x dx = (π/2)·[−cos³x/3]₀^π = (π/2)·(2/3) = π/3 ✅
Q4. (Physics) Ek wire ka resistance 20 Ω hai। Ussi wire ko 4 bar lamba kar dene par (volume constant) naya resistance?
Solution: R = ρl/A; volume = Al constant → lamba karne par A/4. L′ = 4l → R′ = ρ(4l)/(A/4) = 16R = 320 Ω ✅
Q5. (Chemistry) pH = 5 ka buffer banane ke liye CH₃COOH/CH₃COONa ka sahi ratio? (pKa = 4.74)
Solution: Henderson: pH = pKa + log([salt]/[acid]) → 5 = 4.74 + log(r) → r = 10^0.26 ≈ 1.82 : 1 ✅
Q6. (Maths) समीकरण z² + |z|² = 0 का प्रत्येक मूल किस रेखा पर स्थित है? (z complex)
Solution: z = x+iy रखो: (x²−y²+2ixy) + (x²+y²) = 0 → 2x² + 2ixy = 0 → x = 0 या y = 0. Roots: purely real या purely imaginary — axes (real/imaginary) पर ✅
