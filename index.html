About EDUVA — कोटा का स्मार्ट लर्निंग हब

EDUVA सिर्फ एक एआई ऐप नहीं है, बल्कि यह देश की शिक्षा की राजधानी **कोटा** की उस ऊर्जा, अनुशासन और टॉप फैकल्टी के विजन का डिजिटल रूप है जो हर छात्र के सपने को सच करने के लिए 24x7 समर्पित है।

हजारों छात्र जब कोटा आते हैं, तो उन्हें बेहतरीन मेंटरशिप, स्ट्रक्चर्ड कोर्सेज और तुरंत डाउट सॉल्विंग की जरूरत होती है। यही कमी पूरी करने के लिए हमने **'Edu Sir'** AI मेंटर को तैयार किया है जो किसी सख्त शिक्षक की तरह नहीं, बल्कि एक बड़े भाई (Bhaiya/Mentor) की तरह हर छात्र के साथ खड़ा रहता है।

Help & Answers

अक्सर पूछे जाने वाले सवाल (FAQs)

क्या नोट्स या मॉड्यूल्स डाउनलोड किए जा सकते हैं? (DLP Policy)

नहीं भाई! DLP पॉलिसी के तहत सभी मॉड्यूल्स, डीपीपी और टेस्ट पूरी तरह से ऐप के अंदर ही सुरक्षित हैं। छात्र नोट्स डाउनलोड या स्क्रीनशॉट नहीं ले सकते—जो पढ़ना है, वह केवल ऐप पर ही सुरक्षित रूप से पढ़ें।

क्या EDUVA ऐप पूरी तरह से फ्री है?

हाँ भाई! यह ऐप छात्रों के लिए पूरी तरह से 100% फ्री है। यहाँ बिना किसी क्रेडिट लिमिट, सब्सक्रिप्शन या पैसे के आप असीमित डाउट्स पूछ सकते हैं।

फोटो खींचकर डाउट कैसे पूछें?

Chat में 📎 (paperclip) बटन दबाओ → "फोटो खींचें" चुनो → सवाल की साफ photo खींचो। Edu Sir photo पढ़कर तुरंत step-by-step solution दे देंगे — कुछ type करने की ज़रूरत नहीं!

क्या Edu Sir की आवाज़ सुन सकते हैं?

हाँ! हर जवाब के नीचे "Edu Sir को सुनें" बटन दबाओ — पूरा solution आवाज़ में सुनो। Voice Lectures और Viva Examiner में भी Edu Sir बोलते हैं। सबसे अच्छा experience Chrome browser पर मिलता है।

Homework के marks कौन देता है?

AI खुद exam-checker की तरह जाँचता है — हर सवाल 10 में से marks + feedback देता है। रोज़ submit करो, अपना level (Foundation → Board Topper → Olympiad) बढ़ाओ और streak maintain करो!

क्या मेरा डेटा सुरक्षित है?

बिल्कुल। Login Google Firebase के secure servers पर होता है। हम कोई ads नहीं दिखाते, कोई data नहीं बेचते। Logout करते ही इस device का पढ़ाई-वाला data साफ हो जाता है — shared phone पर भी safe।

Internet न हो तो क्या app चलेगी?

App खुलेगी और पुरानी चीज़ें (vault, mistake book) दिखेंगी — पर AI Doubt, Homework और Tests के लिए internet चाहिए। Internet आते ही सब अपने आप चलने लगेगा।

कौन-कौन सी classes और exams के लिए EDUVA है?

Class 6 से 12 तक — CBSE, ICSE और State Boards। साथ में NEET, JEE, Olympiads (NSEJS, IOQM, NMTC), Board exams — सबकी तैयारी एक ही app में, हिंदी में।

App को phone की home screen पर कैसे install करें?

Chrome में app खोलो → ऊपर 3-dots menu → "Add to Home Screen" → Install। EDUVA app की तरह full-screen चलेगी और WhatsApp share में भी EDUVA के नाम से दिखेगी।

Parent Report कैसे काम करता है?

Parent Report section में माँ-बाप का WhatsApp नंबर save करो और "पूरी रिपोर्ट भेजें" दबाओ — test scores, पढ़ाई का समय और सारी progress एक message में पेरेंट्स के पास पहुँच जाती है।

All India EDUVA Test क्या है?

पूरे भारत के बच्चों के साथ एक FREE online test — 25 MCQ, 50 मिनट, class-wise All India Rank। हर participant को Certificate + Analysis, Top 100 को 1 साल और Top 5 को 3 साल की subscription FREE। Test page से FREE register करो!

कोई गलती (bug) दिखे या सुझाव हो तो कहाँ बताएं?

Feedback section से message भेजो — वो सीधे founder तक पहुँचता है। या email करो: team.eduva@gmail.com। अच्छे feature ideas हम जल्दी implement करते हैं! 💪

🗺️ Class-wise Roadmap

                

                    
🌱 Class 6-8
Foundation phase — SOF IMO/NSO, SilverZone, NSEJS की तैयारी शुरू करो

                    
🚀 Class 9-10
NSEJS (मुख्य!), IOQM शुरू करो + SOF — अभी सबसे ज़रूरी समय

                    
👑 Class 11-12
IOQM, NSEP, NSEC, NSEB, NSEA — International Olympiad तक का रास्ता

                

            


            
            

                
🇮🇳 सरकारी Olympiads (सबसे प्रतिष्ठित — IAPT/HBCSE)

                

                    🧪 NSEJS → IJSO (Junior Science Olympiad)
                    

                        
किसे दे सकते हैं: Class 8-10 (उम्र limit लागू, आमतौर पर 15-16 साल से कम)

                        
Syllabus: NCERT Class 9-10 का Physics, Chemistry, Biology + basic reasoning

                        
Pattern: MCQ (लगभग 60-80 सवाल, negative marking के साथ) • महीना: आमतौर पर Nov

                        
रास्ता: NSEJS → INJSO → IJSO (International Junior Science Olympiad!)

                        
तैयारी: NCERT line-by-line + पिछले साल के papers + हर दिन EDUVA पर Olympiad-level practice 🎯

                    

                

                

                    📐 IOQM → INMO → IMO (Maths Olympiad)
                    

                        
किसे दे सकते हैं: Class 8-12 कोई भी

                        
Syllabus: School maths — number theory, geometry, algebra, combinatorics (calculus नहीं!)

                        
Pattern: 30 MCQ (IOQM) • महीना: आमतौर पर Oct-Nov

                        
रास्ता: IOQM → RMO → INMO → IMO Team (International Maths Olympiad!)

                        
तैयारी: Concept clarity + puzzles + Olympiad practice sets — EDUVA ke "🎯 Practice" tab se!

                    

                

                

                    🧮 NMTC (National Mathematics Talent Contest — AMTI)
                    

                        
किसे दे सकते हैं: Class 5-12 — Primary (5-6), Sub-Junior (7-8), Junior (9-10), Intermediate (11-12)

                        
Syllabus: अपनी class का school maths + non-routine problems (logic, patterns, puzzles)

                        
Pattern: दो चरण — Preliminary (MCQ) + Final (descriptive) • महीना: आमतौर पर Oct-Nov

                        
फायदा: AMTI की merit certificates + maths का गहरा confidence — IOQM की बेहतरीन तैयारी!

                        
तैयारी: हर हफ्ते NMTC-pattern practice + पुराने pattern के सवालों का analysis (नीचे Practice section में!)

                    

                

                

                    ⚛️ NSEP / NSEC / NSEB / NSEA (Senior — Physics/Chem/Bio/Astronomy)
                    

                        
किसे दे सकते हैं: Class 11-12 (उस subject में पढ़ रहे हों)

                        
Syllabus: CBSE/NCERT Class 11-12 का पूरा syllabus (अपने subject का)

                        
Pattern: MCQ • महीना: आमतौर पर Nov

                        
रास्ता: NSE → INO → IPhO / IChO / IBO / IOAA 🌍
