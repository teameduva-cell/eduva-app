✅ NCERT Exercise: हल कीजिए: x² − 7x + 12 = 0
गुणनखंडन: (x−3)(x−4) = 0 ⇒ x = 3, 4
🎯 x = 3, 4
✅ NCERT Exercise: 2x² − 4x + 3 = 0 के मूलों की प्रकृति बताइए।
D = (−4)² − 4(2)(3) = 16 − 24 = −8 < 0 ⇒ वास्तविक मूल नहीं
🎯 D = −8, कोई वास्तविक मूल नहीं
✅ NCERT Exercise: दो क्रमागत प्राकृत संख्याओं के वर्गों का योग 365 है। संख्याएँ ज्ञात कीजिए।
n² + (n+1)² = 365 ⇒ 2n² + 2n − 364 = 0 ⇒ n² + n − 182 = 0
⇒ (n+14)(n−13) = 0 ⇒ n = 13
🎯 13 और 14
