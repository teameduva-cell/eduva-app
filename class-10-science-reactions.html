Class 10 Science की सभी important chemical reactions — balanced equations, types और exam tips के साथ।

⚗️ Chapter 1: रासायनिक अभिक्रियाएँ

संयोजन: CaO + H₂O → Ca(OH)₂ (चूना पानी में)
वियोजन: CaCO₃ →(गर्म) CaO + CO₂ ↑
विस्थापन: Fe + CuSO₄ → FeSO₄ + Cu (नीला हरा होता है)
द्वि-विस्थापन: AgNO₃ + NaCl → AgCl ↓ + NaNO₃ (श्वेत अवक्षेप)
रेडॉक्स: CuO + H₂ → Cu + H₂O (CuO अपचयित)
⚡ संतुलित: 2AgBr →(प्रकाश) 2Ag + Br₂ (फोटोग्राफी में)  |  2H₂O →(विद्युत) 2H₂↑ + O₂↑

🧂 Chapter 2: अम्ल, क्षार, लवण

नींद उड़ाने वाली गैस: NH₄Cl + Ca(OH)₂ → CaCl₂ + NH₃↑ + 2H₂O
प्लास्टर ऑफ पेरिस: CaSO₄·2H₂O →(373K) CaSO₄·½H₂O + 1½H₂O
बेकिंग सोडा: NaCl + H₂O + CO₂ + NH₃ → NH₄Cl + NaHCO₃

🔩 Chapter 3: धातु और अधातु

ज़िंक सल्फाइड से Zn: 2ZnS + 3O₂ →(रोस्टिंग) 2ZnO + 2SO₂; ZnO + C →(अपचयन) Zn + CO
हेमेटाइट से Fe: Fe₂O₃ + 3CO → 2Fe + 3CO₂ (वलयण भट्टी में)

🖊️ Chapter 4: कार्बन यौगिक

ज्वलन: CH₄ + 2O₂ → CO₂ + 2H₂O + ऊष्मा
ऑक्सीकरण: C₂H₅OH →(acidified K₂Cr₂O₇) CH₃COOH
एस्टरीकरण: CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O
साबुनीकरण: वसा/तेल + NaOH → साबुन + ग्लिसरॉल
