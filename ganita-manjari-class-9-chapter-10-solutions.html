📖 Chapter Summary

Data = information ka sangrah. Is chapter mein hum seekhte hain data ko **collect, organize, aur interpret** karna — tables, frequencies, mean/median/mode, aur graphs se data ki kahani samajhna. Real-life examples: marks, weather, sports scores, phone usage!

🎯 Key Concepts

  • Data types: qualitative (colors, names) vs quantitative (numbers: marks, height)
  • Frequency = kitni baar value aayi
  • Mean (average) = sab ka yog ÷ count • Median = beech ka value (sort karke) • Mode = sabse zyada aane wala
  • Range = sabse bada − sabse chhota
  • Bar graphs / pie charts se data visualize karo
  • Caution: scale badal ke graphs ko misleading banaya ja sakta hai!

✍️ Original Solved Questions

Q1. Find the mean of: 12, 15, 21, 18, 14.
Solution: Sum = 12+15+21+18+14 = 80. Mean = 80/5 = 16 ✅
Q2. Find the median of: 7, 3, 9, 5, 11.
Solution: Sort karo: 3, 5, 7, 9, 11 → beech ka (3rd) = 7 ✅
Q3. Class 9 students ne favorite color chuna: Red 8, Blue 12, Green 6, Yellow 4 (total 30). (i) Sabse popular? (ii) Blue ka fraction?
Solution: (i) Blue (12) ✅ — ye mode bhi hai. (ii) 12/30 = 2/5 = 40% ✅
Q4. Find the range of: 45, 12, 67, 23, 89, 5.
Solution: Range = max − min = 89 − 5 = 84 ✅
Q5. 5 tests ke marks: 70, 85, 60, 90, 75. Mean aur median dono nikalo.
Solution: Mean = 380/5 = 76 ✅ • Sort: 60, 70, 75, 85, 90 → Median = 75 ✅

📘 Notes in English

  • Data: Collected information. Qualitative (names, colors) vs Quantitative (numbers: marks, heights).
  • Frequency: How many times a value appears. A frequency TABLE organizes raw data.
  • Mean: Sum of all values ÷ number of values. Affected by extreme values.
  • Median: Middle value after arranging in order (even count → average the two middle values). NOT affected by extremes.
  • Mode: Most frequent value. A set can have no mode, one mode, or two (bimodal).
  • Range: Largest − Smallest. Shows spread.
  • Graphs: Bar graphs compare categories; pie charts show parts of a whole; line graphs show change over time.
  • Be alert: Graphs can MISLEAD — check the scale! A small y-axis gap can make tiny differences look huge.

📕 हिंदी में नोट्स

  • आँकड़े (Data): जमा की गई जानकारी। गुणात्मक (नाम, रंग) बनाम मात्रात्मक (संख्याएँ: अंक, लंबाई)।
  • बारंबारता (Frequency): कोई value कितनी बार आई। Frequency TABLE से raw data सुव्यवस्थित होता है।
  • माध्य (Mean): सब का योग ÷ संख्या। बहुत बड़े/छोटे मानों से प्रभावित होता है।
  • माध्यिका (Median): क्रम में लगाने के बाद बीच की value (सम संख्या में दो बीच वालों का औसत)। Extreme values से प्रभावित नहीं।
  • बहुलक (Mode): सबसे ज़्यादा बार आने वाली value। Mode नहीं भी हो सकता, एक भी, या दो भी (bimodal)।
  • परास (Range): सबसे बड़ा − सबसे छोटा। Data के फैलाव को दिखाता है।
  • आलेख: Bar graph — तुलना • Pie chart — हिस्से • Line graph — समय के साथ बदलाव।
  • ⚠️ सतर्क रहो: आलेख धोखा दे सकते हैं — scale देखो! y-axis की छोटी-सी गड़बड़ी छोटे अंतर को बहुत बड़ा दिखा देती है।

➕ Extra Practice — same level (original)

➕ Data: 4, 7, 7, 9, 12, 7, 4. Mode aur range nikalo.
Answer: Mode = 7 ✅ (3 baar aaya) • Range = 12 − 4 = 8 ✅
➕ Mean 20 hai 5 numbers ka. Ek number 30 galat se 50 likha gaya tha. Sahi mean?
Answer: Galat yog = 20×5 = 100; sahi yog = 100 − 50 + 30 = 80 → sahi mean = 80/5 = 16 ✅
➕ Kab median mean se behtar average hai? Example do.
Answer: Jab extreme value ho: salaries 10k, 12k, 15k, 18k, 1 lakh — mean ≈ 31k (misleading), median = 15k (sahi picture) ✅

📗 Exercise Set 10.1 — Weighted Mean (5 Questions)

Q1. Two sections: A mean 72 (30 students), B mean 76 (25 students) — combined average?
Weighted mean: (72×30 + 76×25) / 55 = (2160 + 1900)/55 = 4060/55 = 73.82 (approx) ✅
Q2. Three equal quantities of fertilisers: 1/10, 9/50, 3/60 nitrogen — fraction in mixture?
Equal quantities → simple average of fractions: common denominator 300: 30/300 + 54/300 + 15/300 = 99/300 = 33/100 ✅
Q3. ⭐ Gold: 9 units @12 varna, 5 @10, 17 @11 — purity of combined gold?
Weighted mean = (9×12 + 5×10 + 17×11) / (9+5+17) = (108+50+187)/31 = 345/31 = 11.13 varna ✅
Q4. Rainfall/day: May 3.5mm, June 10mm, July 8.7mm — combined average expression?
(3.5×31 + 10×30 + 8.7×31) / (31+30+31) — days as weights. Expression form ✅
Q5. Spice mix: (i) 100mL@5% + 200mL@10% + 300mL@15% (ii) 300@5% + 200@10% + 100@15% — concentrations?
(i) (100×5 + 200×10 + 300×15)/600 = (500+2000+4500)/600 = 7000/600 = 11.67% ✅
(ii) (300×5 + 200×10 + 100×15)/600 = (1500+2000+1500)/600 = 5000/600 = 8.33% ✅
💡 Same ingredients, alag quantities → alag result! Weights matter.

📗 Exercise Set 10.2 — Custom Weights (MCQ + 2 situations)

Q1. Savitri: 35/50, 44/60, 80/100 — ratio 3:4:5 — annual score expression?
Pehle har score ko % mein convert karo: (35/50)×100 = 70%, (44/60)×100 ≈ 73.3%, 80%. Phir weighted mean with 3:4:5.
Correct expression: (iv) — [(35/50)×100]×3 + [(44/60)×100]×4 + [80]×5, all ÷ (3+4+5) ✅
(Ya phir: pehle fraction form (iii) — ye bhi valid hai kyunki ×100 baahar hai. Dono (iii) aur (iv) correct hain!)
Hotel rating (4:3:2 weights, ratings 5,3,4): (5×4 + 3×3 + 4×2)/9 = (20+9+8)/9 = 37/9 = 4.11 ✅

📗 Exercise Set 10.3 — Mixtures & Combined Data (7 Qs)

Q1. ₹8000 books (30% profit) + ₹1000 covers (50% profit) — % profit on total sales?
Total sales = 9000. Profit = 2400 + 500 = 2900. % = 2900/9000 × 100 = 32.22% ✅
Q2. Stork: 20 days avg 44.5 km/day, 21st day 55 km — new avg (21 days)?
Total = 20×44.5 = 890. New total = 890+55 = 945. Avg = 945/21 = 45 km/day ✅ (Guess: thoda upar jayega kyunki 55 > 44.5)
Q3. 600mL@5% salt + 300mL@8% sugar — concentrations in mixture?
Total = 900mL. Salt = 600×0.05 = 30mL → 30/900 = 3.33% ✅ • Sugar = 300×0.08 = 24mL → 24/900 = 2.67% ✅ (Option v)
Q4. ⭐ Panipuri pani: 10L @ 8% spice — kitna paani milao ki (3/4)th ho jaye?
Spice amount fixed = 0.8L. New concentration = 6% (kyunki 8×3/4=6). New volume V: 0.8/V = 0.06 → V = 0.8/0.06 = 13.33L. Paani add = 13.33 − 10 = 3.33 litres ✅
Q5. Fitness ratio 4:5:6 — Rashi (60,65,70) vs Keerthi (55,65,75): (i) bina calculate kaun zyada? (ii) final marks?
(i) Keerthi ✅ — agility (sabse bada weight 6) mein zyada, baaki barabar.
(ii) Rashi = (60×4+65×5+70×6)/15 = (240+325+420)/15 = 985/15 = 65.67 ✅
Keerthi = (55×4+65×5+75×6)/15 = (220+325+450)/15 = 995/15 = 66.33 ✅
Q6. Restaurant ratings (table) — weights food:ambience:service = 6:5:4 — average?
Food avg = (5×5+3×4+2×3+0+0)/10 = (25+12+6)/10 = 4.3
Ambience = (0+4×4+5×3+1×2+0)/10 = (16+15+2)/10 = 3.3
Service = (1×5+2×4+2×3+4×2+1×1)/10 = (5+8+6+8+1)/10 = 2.8
Weighted = (4.3×6 + 3.3×5 + 2.8×4)/15 = (25.8+16.5+11.2)/15 = 53.5/15 = 3.57 ✅
Q7. ⭐ Langurs: male 16.5kg, female 13.8kg, all 14.925kg, total 60 — (i) which expression? (ii) male count (iii)-(v) updates?
(i) (a) ✅ — (16.5x + 13.8y)/(x+y) = 14.925
(ii) 16.5x + 13.8(60−x) = 14.925×60 → 16.5x + 828 − 13.8x = 895.5 → 2.7x = 67.5 → x = 25 males ✅ (35 females)
(iii) Female 15.2kg added: new avg = (13.8×35 + 15.2)/36 = (483+15.2)/36 = 498.2/36 = 13.84 kg ✅
(iv) Two males (16.9, 16.1) released: remaining 23 males, new sum = 16.5×25 − 33 = 379.5 → avg = 379.5/23 = 16.5 kg ✅
(v) One male −1kg: 378.5/23 = 16.46 kg ✅

EOC Q6/Q15. Weights doubled / increased by 1 — weighted avg par effect?

❓ FAQs

Mean, median, mode mein kab kaun use karein?

Average performance ke liye mean; beech ka student dekhna ho toh median; sabse common (favorite color/category) ke liye mode.

Median kab mean se behtar hai?

Jab data mein bahut bada/chhota extreme value ho (jaise 1 student ka 100/100 baaki sab 40s) — median distort nahi hota.

Chapter exam mein kya aata hai?

Frequency tables, mean/median/mode ke short numericals, aur 'is graph mein kya galat hai' reasoning questions.
