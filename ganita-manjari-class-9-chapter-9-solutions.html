📖 Chapter Summary

Ye chapter mathematical **logic** se shuru hota hai — kaunsi statements sach ya jhooth ho sakti hain (propositions), aur 'agar... to...' wale statements (implications) ke alag-roop: converse, inverse, contrapositive. Geometry ke theorems (jaise Pythagoras) ke saath inka connection samajhna is chapter ka dil hai.

🎯 Key Concepts

  • Proposition = wo statement jo true YA false ho sakti ho ('What time is it?' proposition nahi)
  • Implication: 'If p, then q' — p = hypothesis, q = conclusion
  • Converse: 'If q, then p' (order ulti) — hamesha sach nahi hoti!
  • Inverse: 'If not p, then not q' • Contrapositive: 'If not q, then not p' — original ke barabar truth value rakhti hai
  • Counterexample: ek hi example jo statement ko jhooth saabit kar de (15, divisible by 5 but not 10)
  • Biconditional: 'p if and only if q' — dono direction mein sach ho tabhi poora sach

✍️ Original Solved Questions

Q1. Statement do: (a) 'Delhi is the capital of India.' (b) 'What time is it?' — kaunsi proposition hai aur kyun?
Solution: (a) Proposition hai — ye true ya false ho sakti hai (ye true hai). (b) Proposition nahi — sawal hai, true/false nahi hota. ✅
Q2. Statement: 'If a number is divisible by 10, then it is divisible by 5.' (i) Kya ye true hai? (ii) Converse likho — kya wo true hai?
Solution: (i) True — 10 ke multiples 5 ke bhi hote hain. (ii) Converse: 'If a number is divisible by 5, then it is divisible by 10.' — FALSE ✅ (counterexample: 15, 25...)
Q3. Pythagoras statement: 'If a triangle is right-angled, then a² + b² = c².' Iska converse likho aur batao sach hai ya nahi.
Solution: Converse: 'If a² + b² = c², then the triangle is right-angled.' — ye TRUE ✅ hai (yehi Pythagoras ka Converse Theorem hai!). Dekha — converse kabhi kabhi sach bhi hota hai!
Q4. p → q ke liye inverse aur contrapositive likho: 'If x² = 25, then x = 5.'
Solution: Inverse: 'If x² ≠ 25, then x ≠ 5' • Contrapositive: 'If x ≠ 5, then x² ≠ 25.' Original false hai (x = −5), aur contrapositive bhi false (x = −5 ⇒ x² = 25) — dono ka truth value same ✅
Q5. 'If a quadrilateral is a square, then it is a rectangle.' Converse banao aur check karo.
Solution: Converse: 'If a quadrilateral is a rectangle, then it is a square.' — FALSE ✅ (lambi chaudi rectangle square nahi hoti).

📘 Notes in English

  • Proposition: A sentence that is either TRUE or FALSE (not both). Questions, commands, and exclamations are NOT propositions.
  • Implication (p → q): 'If p, then q' — p is the hypothesis, q is the conclusion.
  • Converse (q → p): Swap the two parts. Warning: a true implication can have a FALSE converse (divisible by 10 → 5 is true; converse is false).
  • Inverse (~p → ~q): Negate both parts. Has the SAME truth value as the converse.
  • Contrapositive (~q → ~p): Swap AND negate. Always has the SAME truth value as the original — this is why we use it in proofs!
  • Counterexample: ONE example that breaks a statement is enough to prove it false (15 breaks 'divisible by 5 → 10').
  • Biconditional (p ↔ q): 'p if and only if q' — true only when BOTH directions hold.
  • Memory trick: Converse = swap • Inverse = negate • Contrapositive = swap + negate.

📕 हिंदी में नोट्स

  • प्रतिपादन (Proposition): वाक्य जो TRUE या FALSE हो (दोनों नहीं)। सवाल, हुक्म, वाक्यांश — proposition नहीं होते।
  • निहितार्थ (p → q): 'यदि p, तो q' — p = पक्षय, q = निष्कर्ष।
  • व्युत्क्रम Converse (q → p): दोनों हिस्से उलट दो। ⚠️ सावधान: सच statement का converse झूठा हो सकता है (10 से divisible → 5 सही; उल्टा गलत)।
  • प्रतिलोम Inverse (~p → ~q): दोनों का इनकार करो। इसकी truth value converse जैसी ही होती है।
  • व्याप्ति/Contrapositive (~q → ~p): उलटो + इनकार करो। इसकी truth value हमेशा original जैसी — proof में इसीलिए use होता है!
  • प्रत्युदाहरण (Counterexample): एक ही उदाहरण काफी है statement झूठा साबित करने के लिए (15 ने '5 से divisible → 10' तोड़ दिया)।
  • दिशानिर्देशित (p ↔ q): 'p यदि और केवल यदि q' — दोनों दिशाओं में सच हो तभी सच।
  • याद रखने की तरकीब: Converse = उलटना • Inverse = इनकार • Contrapositive = उलटना + इनकार।

➕ Extra Practice — same level (original)

➕ Converse likho: 'If a figure is a square, then it has four equal sides.' Kya converse sach hai?
Answer: Converse: 'If a figure has four equal sides, then it is a square.' — FALSE ✅ (rhombus ke bhi 4 barabar sides hote hain, wo square nahi hota)
➕ Statement: 'If x is even, then x² is even.' (i) Contrapositive (ii) Kya statement sach?
Answer: (i) Contrapositive: 'If x² is not even, then x is not even.' (ii) TRUE ✅ (even × even = even)
➕ Inverse aur converse ka relation batao.
Answer: Dono ki truth value hamesha same ✅ hoti hai — ek sach toh dono sach, ek jhooth toh dono jhooth. (Original se dono alag ho sakte hain!)

📗 Exercise Set 9.1 — Solutions (Question-wise)

Apni NCERT book ke Exercise 9.1 ke questions ke saath ye solutions match karo. Solutions EDUVA ke apne likhe hue hain (sirf solutions — question text book se hi padho). ⭐ = hard question.

Q1. Parallel lines → corresponding angles (converse task)
Original: TRUE ✅ — corresponding angles axiom ke hisaab se parallel lines ke corresponding angles barabar hote hain. Converse: TRUE ✅ — "Corresponding angles equal ⇒ lines parallel" — ye parallel lines test karta hai. Dono sach!
Q2. Square → all angles equal
Original: TRUE ✅ (square ke sab angles 90°). Converse: FALSE ❌ — counterexample: rectangle ke sab angles barabar (90°) hote hain par wo square nahi hota.
Q3. ⭐ Incentre wala: AB = AC ⇒ IE = IF
Original: TRUE ✅ — AB = AC ⇒ ∠B = ∠C. Ab ΔBIF aur ΔCIE mein: ∠FBI = ∠ECI (aadhe angles barabar), BI = CI (equal angles ke saamne), ∠BIF = ∠CIE (vertically opposite) ⇒ ΔBIF ≅ ΔCIE (ASA) ⇒ IE = IF. Converse: FALSE ❌ — IE = IF aise triangles mein bhi ho sakta hai jahan AB ≠ AC (jaise ∠A = 60° wale triangles mein ye condition hamesha milti hai) — isliye IE = IF se AB = AC prove nahi hota.
Q4. x = y ⇒ a + x = a + y
Original: TRUE ✅ (equality mein same number jodne par equality bani rehti hai). Converse: TRUE ✅ — a + x = a + y ke dono side se a ghatao ⇒ x = y. Yehi equations solve karne ka base hai!
Q5. a, b perfect squares ⇒ ab perfect square
Original: TRUE ✅ — a = m², b = n² ⇒ ab = (mn)². Converse: FALSE ❌ — counterexample: a = 2, b = 8 → ab = 16 = 4² (perfect square), par na 2 na 8 khud perfect square hai!
Q6. x = y ⇒ x² = y²
Original: TRUE ✅ (dono sides ka square). Converse: FALSE ❌ — counterexample: x = 3, y = −3 → x² = y² = 9, par x ≠ y. ⚠️ Isliye x² = 25 se x = ±5 aata hai, sirf 5 nahi!
Q7. x = y ⇒ x³ = y³
Original: TRUE ✅. Converse: TRUE ✅ (real numbers ke liye) — x³ − y³ = (x − y)(x² + xy + y²), aur doosra factor sirf x = y = 0 par zero hota hai. Isliye x³ = y³ ⇒ x = y. Cube root unique hota hai!
Q8. Divisible by 24 ⇒ by 4 and 6
Original: TRUE ✅ — n = 24k = 4(6k) = 6(4k). Converse: FALSE ❌ — counterexample: n = 12 → 4 se bhi, 6 se bhi divisible, par 24 se nahi! (LCM(4,6) = 12, 24 nahi.)
Q9. Divisible by 60 ⇒ by 5 and 12
Original: TRUE ✅ — n = 60k = 5(12k) = 12(5k). Converse: TRUE ✅ — 5 aur 12 coprime hain (LCM = 60), isliye jo number dono se divisible wo unke product 60 se bhi divisible. Dono sach!
Q10. n = p² (p prime) ⇒ exactly 3 factors
Original: TRUE ✅ — factors sirf 1, p, p². Converse: TRUE ✅ — agar n ke exactly 3 factors hain, toh ek factor khud se pair hota hai ⇒ n = d², aur d prime hi hoga (warna aur factors ban jaate). Dono sach!
Q11. n = pq (unequal primes) ⇒ exactly 4 divisors
Original: TRUE ✅ — divisors: 1, p, q, pq. Converse: FALSE ❌ — counterexample: n = 8 = 2³ → divisors 1, 2, 4, 8 (exactly 4), par 8 do primes ka product nahi hai!
Q12. n aur n+3 ke common factors nahi ⇒ n multiple of 3 nahi
Original: TRUE ✅ — (contrapositive se:) agar n = 3k hota, toh n + 3 = 3(k+1) bhi 3 se divisible — 3 common factor ban jaata. Converse: TRUE ✅ — common divisor hamesha (n+3) − n = 3 ko divide karta hai, matlab common factor sirf 1 ya 3 ho sakta hai. Agar n multiple of 3 nahi, toh 3 common factor nahi ⇒ koi common factor nahi. Dono sach!
Q13. Counterexamples dhoondho (primes waale claims)
(i) 4n² + 1 sab prime? — n = 4: 4(16)+1 = 65 = 5×13 ❌
(ii) n² + n + 11 sab prime? — n = 10: 100+10+11 = 121 = 11² ❌
(iii) 4ⁿ + 3 sab prime? — n = 4: 256+3 = 259 = 7×37 ❌
Q14. Counterexamples (2ⁿ waale)
(i) n prime ⇒ 2ⁿ − 1 prime? — n = 11: 2¹¹ − 1 = 2047 = 23×89 ❌ (famous Mersenne counterexample!)
(ii) n even ⇒ 2ⁿ + 1 prime? — n = 6: 64+1 = 65 = 5×13 ❌
Q15. Divisible by 8 ⇒ by 2 and 4
(i) TRUE ✅ — n = 8k = 2(4k) = 4(2k).
(ii) NAHI ❌ — 2 aur 4 se check karna kaafi nahi! Counterexample: n = 12 — 2 aur 4 se divisible, par 8 se nahi. (Kyunki 2 aur 4 coprime nahi hain.) 8 ka shortcut: last 3 digits 8 se divisible honi chahiye.
Q16. Divisibility rule of 3 — 'If-then' mein
"If a number is divisible by 3, then the sum of its digits is a multiple of 3." Aur converse bhi: "If the sum of the digits of a number is a multiple of 3, then the number is divisible by 3." (Dono sach — isliye ye rule kaam karta hai!)
Q17. ⭐ Sticks = diagonals wala
(i) Property: type Q ⇒ equal diagonals.
(a) Ha — sticks BARABAR hone chahiye (type Q ke diagonals barabar hote hain; sticks hi diagonals hain!).
(b) Ha — arrangement matter karta hai. Sirf barabar sticks kaafi nahi — quadrilateral type Q tabhi banega jab diagonals Q ki poori definition poori karein (jaise rectangle ke liye diagonals ko aapas mein bisect bhi karna hota hai).
(ii) Property (converse): equal diagonals ⇒ type Q.
(a) Ha — barabar sticks zaroori (diagonals barabar hone chahiye).
(b) Nahi — arrangement matter nahi karta! Property ke hisaab se equal diagonals wala har quadrilateral type Q hai — jo bhi angle/crossing ho. Yehi farak hai original aur converse mein! 🎯

❓ FAQs

Converse hamesha sach kyun nahi hota?

Kyunki conclusion se wapas hypothesis nahi nikalta hamesha — 'divisible by 10 → 5' sach hai par ulta nahi. Sirf special cases (definitions, iff statements) mein converse bhi sach hoti hai.

Contrapositive kyun useful hai?

Contrapositive original ke BARABAR truth value rakhta hai — proofs mein kabhi kabhi contrapositive prove karna aasan hota hai.

Ye chapter exam mein kaise aata hai?

Converse/inverse/contrapositive identify karne, counterexample dene, aur true/false justify karne ke MCQ/short questions — logic-based hote hain.
