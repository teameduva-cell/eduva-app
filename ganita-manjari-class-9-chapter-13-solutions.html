📘 Notes in English

  • Linear equation in 2 variables: ax + by + c = 0 (a, b not both 0). Graph = straight line.
  • Solutions: Every point on the line is a solution — infinitely many solutions.
  • Standard form: arrange as ax + by = c. x = 8 means 1x + 0y = 8 (b = 0 allowed!).
  • Slope (m): steepness = rise/run = (y₂−y₁)/(x₂−x₁). Positive = up left→right; negative = down.
  • Slope-intercept form: y = mx + c — m = slope, c = y-intercept.
  • x-intercept: set y = 0 → x = −c/m (if m ≠ 0).
  • Pair of lines: compare a₁/a₂, b₁/b₂, c₁/c₂: intersect (unique solution) / parallel (no solution) / coincident (infinite solutions).
  • Trick for symmetric systems (like 9x+7y=107, 7x+9y=101): ADD and SUBTRACT the equations!

📕 हिंदी में नोट्स

  • दो चरों में रैखिक समीकरण: ax + by + c = 0 (a, b दोनों शून्य नहीं)। आलेख = सीधी रेखा।
  • हल: रेखा का हर बिंदु एक हल — अनंत हल होते हैं!
  • ढलान (slope): m = (y₂−y₁)/(x₂−x₁) — ऊपर जाए तो +, नीचे जाए तो −।
  • y = mx + c: m = ढलान, c = y-अंतःखंड (जहाँ रेखा y-axis को काटे)।
  • रेखा-युग्म: a₁/a₂, b₁/b₂, c₁/c₂ compare करो — एक हल / कोई हल नहीं / अनंत हल।
  • सममित प्रणाली (गुणांक उल्टे हों: 9x+7y=107, 7x+9y=101) — समीकरणों को जोड़ो और घटाओ — सबसे तेज़ तरीका!

📗 Exercise Set 13.1 (3 Qs)

Q1. a = 3, b = 0, c = −1/5 — linear equation likho?
Standard form: 3x + 0y = −1/5, ya 3x + 1/5 = 0 (y absent — b = 0 allowed, line vertical) ✅
Q2. Table: y−15 = √2x • 3y−2x = 0 • 5x = 3y • x = 8 • 3y = 1 — standard form + coefficients?
y−15 = √2x → √2x − y = −15 (a=√2, b=−1, c=−15)
3y−2x = 0 → 2x − 3y = 0 (a=2, b=−3, c=0)
5x = 3y → 5x − 3y = 0 (a=5, b=−3, c=0)
x = 8 → 1x + 0y = 8 (a=1, b=0, c=8)
3y = 1 → 0x + 3y = 1 (a=0, b=3, c=1) ✅
Q3. (i) t = 2p vs p = 2t — kaun sahi? (ii) x + y = 176 — sahi representation?
(i) Notebook ki cost = pen se DOUBLE: t = 2p sahi ✅ (p = 2t ulti baat).
(ii) Ha — x + y = 176 sahi hai: do batsmen ke runs ka yog 176 ✅

📗 Exercise Set 13.2 (7 Qs)

Q1. Kya (4, 3), 5x − 6y = 2 ka solution hai?
5(4) − 6(3) = 20 − 18 = 2 = RHS → HAAN, solution hai ✅
Q2. Do solutions nikalo: (i) 7x − 3y = 21 (ii) 2x + 3y = 5
(i) x = 0 → y = −7; x = 3 → y = 0 ✅
(ii) x = 1 → y = 1; x = 4 → y = −1 ✅
Q3. 2mx + 3y = 7; 4x + ny = −10 — (2, −1) common solution hai — m, n?
(2,−1) substitute: 2m(2) + 3(−1) = 7 → 4m = 10 → m = 2.5 • 4(2) + n(−1) = −10 → n = 18 ✅
Q4. Alag-alag quadrants mein do solutions: (i) 5x+3y=7 (ii) 5x−3y=7 (iii) −5x+3y=7 (iv) −5x−3y=7
(i) Q1: (2,−1) Q2: (−1, 4) ✅
(ii) Q1: (2,1) Q4: (−1, −4) ✅
(iii) Q2: (−1, 2)? check: 5+6=11≠7... (−2, −1): 10−3=7 ✓ Q1: (1, 4)? −5+12=7 ✓
(iv) Q3: (−2, −1): 10+3=13✗... (−1, −4): 5+12=17✗ — Q2: (−2, 1): 10−3=7 ✓ Q3: (2, −5): −10+15=5✗... (−1,−4): 5+12 = 17 ✗. Q4: (1,−4): −5+12=7 ✓ Q2: (−2,1) ✓ ✅
Q5. 3x − 7y = 21 — kya C(2,3) line pe? Equation satisfy kare?
Graph: C line pe NAHI hai. Check: 3(2) − 7(3) = 6 − 21 = −15 ≠ 21 → satisfy nahi karta. Line ke bahar ke points equation satisfy nahi karte ✅ (graph = solution set)
Q6. T/F: (i) sirf ek solution (ii) hamesha origin se (iii) kabhi rational nahi (iv) x=3 valid 2-variable eq (v) 2x+3y=7 ke infinite solutions (vi) (1,2) is 2x+3y=7 ka solution?
(i) F ❌ (infinite) (ii) F ❌ (c ≠ 0 toh nahi) (iii) F ❌ (2x+3y=7 → (2,1) rational) (iv) T ✅ (y ka coefficient 0) (v) T ✅ (vi) 2+6=8≠7 → F ❌ ✅
Q7. 3x+4y=7 aur 6x+8y=14 — same solutions? General: ax+by=c aur kax+kby=kc?
(i) Ha — dusri equation pehli ka 2× hai — same line, same points ✅
(ii) Proof: (x,y) pehli ka solution ⇒ a(kx)+b(ky) = k(ax+by) = kc ✓. Ulta: kax+kby=kc, k≠0 ⇒ divide by k ⇒ ax+by=c ✓ Same solution set ✅

📗 Exercise Set 13.3 — Slope (4 Qs)

Q1. Ski hills rank karo (steepness): A: 60/70, B: 60/110, C: 80/100?
Slopes: A = 60/70 ≈ 0.857 • B = 60/110 ≈ 0.545 • C = 80/100 = 0.8
Order (least→greatest): B < C < A ✅
Q2. Ramp: 2.5 m rise, 4 m run — slope?
m = rise/run = 2.5/4 = 0.625 ✅
Q3. Graphs ki slope: (i) horizontal line (ii) falling diagonal (iii) rising diagonal (iv) vertical line?
(i) m = 0 (horizontal) ✅ (ii) negative (falling) — count units: rise −k, run +k → m = −1 (approx graph se) ✅ (iii) positive — m ≈ 1 ✅ (iv) undefined (vertical — run = 0, division by zero!) ✅
Q4. Wheelchair ramp: 1 cm rise per 12 cm run — 18 cm height ke liye kitni length?
Ratio 1:12 → horizontal = 12 × 18 = 216 cm ✅

📗 Exercise Set 13.4 — Forming Pairs (3 situations)

Q1. Movie tickets ₹x, snack ₹y: (i) 2 tickets + 3 snacks = ₹850 (ii) 4 tickets + 1 snack = ₹1100?
(i) 2x + 3y = 850 ✅ (ii) 4x + y = 1100 ✅
Q2. Taxi: fixed ₹x, per km ₹y: (i) 6 km → ₹122 (ii) 8 km → ₹160?
(i) x + 6y = 122 ✅ (ii) x + 8y = 160 ✅
Q3. Adults ₹150, children ₹100 — 200 log, ₹25,000 — x adults, y children?
x + y = 200 ✅ • 150x + 100y = 25000 ✅

📗 Exercise Set 13.5 — Solving Word Problems (9 Qs)

Q1. (i) Sum = 5, difference = −21 (ii) difference 26, one = 3× other (iii) 7 bats + 6 balls = ₹8880; 3 bats + 5 balls = ₹4000 (iv) Taxi: 10 km ₹155; 15 km ₹220 — fixed + per km? 25 km ka fare? (v) fraction: (x+2)/(y+2) = 9/11, (x+3)/(y+3) = 5/6 (vi) (x+1)/(y−1) = 1, x/(y+1) = 1/2 (vii) Nuri/Sonu ages (viii) 2-digit: digit sum 9, 9×number = 2×reversed (ix) ₹2000: ₹50 & ₹100 notes, 25 total (x) library: Saritha 7 days ₹27, Susy 5 days ₹21?
(i) x + y = 5, x − y = −21 → x = −8, y = 13 ✅
(ii) x − y = 26, x = 3y → 2y = 26 → y = 13, x = 39 ✅
(iii) 7b + 6l = 8880; 3b + 5l = 4000 → ×: 35b+30l = 44400; 18b+30l = 24000 → 17b = 20400 → b = 1200; l = (4000−3600)/5 = 80 ✅
(iv) x + 10y = 155; x + 15y = 220 → 5y = 65 → y = 13, x = 25. 25 km: 25 + 25×13 = ₹350 ✅
(v) 11(x+2) = 9(y+2) → 11x − 9y = −4; 6(x+3) = 5(y+3) → 6x − 5y = −3. Solve: x = 7, y = 9 → fraction 7/9 ✅
(vi) x + 1 = y − 1 → x − y = −2; 2x = y + 1. Solve: x = 3, y = 5 → 3/5 ✅
(vii) N−5 = 3(S−5); N+10 = 2(S+10) → N = 3S − 10; N = 2S + 10 → S = 20, N = 50 ✅
(viii) x + y = 9; 9(10x + y) = 2(10y + x) → 90x + 9y = 20y + 2x → 88x = 11y → y = 8x. x=1,y=8 → number 18 ✅
(ix) x + y = 25; 50x + 100y = 2000 → x + 2y = 40 → y = 15, x = 10 ✅
(x) f + 4a = 27 (7 days = 3 + 4 extra); f + 2a = 21 → 2a = 6 → a = 3, f = ₹15 ✅
Q2. Quiz: 10 students, girls = boys + 4 — graphically?
b + g = 10; g = b + 4 → g = 7, b = 3 ✅
Q3. Intersect/parallel/coincident: (i) 5x−4y+8=0; 7x+6y−9=0 (ii) 9x+3y+12=0; 18x+6y+24=0 (iii) 6x−3y+10=0; 2x−y+9=0?
(i) 5/7 ≠ −4/6 → intersecting ✅ (ii) 9/18 = 3/6 = 12/24 → coincident ✅ (iii) 6/2 = −3/−1 = 3 ≠ 10/9 → parallel ✅
Q4. Solutions hain? (i) x+y=5, 2x+2y=10 (ii) x−y=8, 3x−3y=16 (iii) 2x+y−6=0, 4x−2y−4=0 (iv) 2x−2y−2=0, 4x−4y−5=0?
(i) Coincident — infinite ✅ (ii) 1/3 = −1/−3 ≠ 8/16 — parallel — no solution ✅ (iii) 2/4 ≠ 1/−2 → intersect — solve: x = 2, y = 2 ✅ (iv) 2/4 = −2/−4 ≠ −2/−5 → parallel — no solution ✅
Q5. Garden: half-perimeter = 36, length = width + 4 — dimensions?
l + b = 36; l = b + 4 → b = 16, l = 20 m ✅
Q6. 2x+3y−8=0 ke saath: (i) intersecting (ii) parallel (iii) coincident — doosri equation?
(i) 3x + 3y − 8 = 0 (ratios 2/3 ≠ 3/3) ✅ (ii) 4x + 6y − 10 = 0 (2/4 = 3/6 ≠ −8/−10) ✅ (iii) 4x + 6y − 16 = 0 (sab ratio = 2) ✅
⭐Q7. Mahāvīrāchārya: 9 citrons + 7 wood-apples = 107; 7 citrons + 9 wood-apples = 101 — prices?
Add: 16x + 16y = 208 → x + y = 13. Subtract: 2x − 2y = 6 → x − y = 3. Solve: x = 8, y = 5. Citrons ₹8, wood-apples ₹5 ✅ (Special structure — coefficients interchanged!)
Q8. 5 pencils + 7 pens = ₹50; 7 pencils + 5 pens = ₹46 — prices?
Add: 12p + 12q = 96 → p + q = 8. Subtract: −2p + 2q = 4 → q − p = 2. → p = 3, q = 5. Pencil ₹3, pen ₹5 ✅
Q9. Stool ki height (cat wala — 85 cm & 25 cm)?
Let stool = s, cat standing = c₁, sitting = c₂. s + c₁ = 85; s − c₂ = 25... classic problem: assume cat same: s + c = 85; s − c = 25 → s = 55 cm ✅ (add both equations)

📗 End-of-Chapter Exercises (16 Qs)

Q1. y = 3x graph: (i) slope? (ii) y-intercept? (iii) tank: 5 min pe kitna height? 21 cm kitne min? (iv) (4,10) line pe? (v) x = 3 se intersection?
(i) m = 3 (rise/run = 6/2) ✅ (ii) c = 0 (origin se) ✅ (iii) 5 min → 15 cm; 21 cm → 7 min ✅ (iv) 3×4 = 12 ≠ 10 → NAHI ✅ (v) x = 3 → y = 9 → point (3, 9) ✅
Q2. F = (9/5)C + 32: (ii) 30°C → ? (iii) 95°F → ? (iv) 0°C → ? 0°F → ? (v) numerically equal temperature?
(ii) F = 54 + 32 = 86°F ✅ (iii) 95 = 1.8C + 32 → C = 35°C ✅ (iv) 0°C = 32°F; 0°F = −160/9 ≈ −17.8°C ✅ (v) F = C: x = 1.8x + 32 → −0.8x = 32 → x = −40 ✅ (−40° = −40°F!)
Q3. Graphically solve: 2x + y = 6; 2x − y − 2 = 0?
Add: 4x = 8 → x = 2, y = 2. Lines intersect at (2, 2) ✅
Q5. y = mx + c ka x-intercept formula?
y = 0 → mx = −c → x = −c/m (m ≠ 0) ✅
Q6. Plan A: ₹50 + ₹0.20/min; Plan B: ₹30 + ₹0.30/min — kab kaun sasta? Equal kab?
50 + 0.2m = 30 + 0.3m → m = 200. A cheaper: m > 200; B cheaper: m < 200; equal: 200 min ✅
Q7. (i) given slope — kitni lines? (ii) given slope + point?
(i) Infinite (parallel family) ✅ (ii) Exactly one ✅
Q8. 4x + py + 8 = 0; 2x + 2y + 2 = 0 — unique solution ke liye p?
Unique: 4/2 ≠ p/2 → p ≠ 4 ✅
Q9. (a+b)x − 2by = 5a + 2b + 1; 3x − y = 14 — infinite solutions ke liye a, b?
Coincident: (a+b)/3 = −2b/−1 = (5a+2b+1)/14. From 2nd: 2b = 3(a+b)/... let me: (a+b)/3 = 2b → a + b = 6b → a = 5b. And (5a+2b+1)/14 = 2b → 5a + 2b + 1 = 28b → 5a = 26b − 1 → 25b = 26b − 1 → b = 1, a = 5. a = 5, b = 1 ✅
Q10. x + 2y = 3; (k−1)x + (k+1)y = k+3 — coincident ke liye k?
1/(k−1) = 2/(k+1) = 3/(k+3). From first two: k+1 = 2k−2 → k = 3. Check: 1/2 = 2/4 = 3/6 ✓ k = 3 ✅
Q11. Robot 1: (0,0) se 3 right + 4 up repeatedly; Robot 2: (10,0) se 1 right + 2 up — intersect? (ii) R1: (3,0) se 5 right + 5 up; R2: (7,0) se 5 right + 3 down?
(i) R1 path: slope 4/3 through origin → y = 4x/3. R2: slope 2 through (10,0) → y = 2(x−10). Intersect: 4x/3 = 2x − 20 → 4x = 6x − 60 → x = 30, y = 40 → (30, 40) ✅ (check repeated-move structure: R1 at step 10: (30,40) ✓; R2 at step 20: (30,40) ✓)
(ii) R1: y = x − 3 (from (3,0), slope 1). R2: slope −3/5 from (7,0) → y = −3(x−7)/5. Intersect: x − 3 = −3x/5 + 21/5 → 5x − 15 = −3x + 21 → 8x = 36 → x = 4.5, y = 1.5 → (4.5, 1.5) ✅
⭐Q12. Watch: 'a' min after 2 o'clock; 15 min later 'b' min after 3 — a = 6b — second time kya tha?
15 min baad: (2:00 + a + 15) = 3:(a−45)... time line: a minutes after 2 = 120 + a minutes from 12. b after 3 = 180 + b. 180 + b = 120 + a + 15 → a − b = 45. Given a = 6b → 5b = 45 → b = 9, a = 54. Second time: 3:09 ✅
⭐Q13. Digit sum 15; reversed exceeds by 9 — number?
x + y = 15; (10y + x) − (10x + y) = 9 → 9(y − x) = 9 → y = x + 1. So x = 7, y = 8 → number 78 ✅
⭐Q14. Cyclic quad: ∠A = x+7, ∠B = y+8, ∠C = 3y+23, ∠D = 4x+12 — angles?
Cyclic: ∠A + ∠C = 180 → x + 7 + 3y + 23 = 180 → x + 3y = 150. ∠B + ∠D = 180 → y + 8 + 4x + 12 = 180 → 4x + y = 160. Solve: from 2nd y = 160 − 4x; sub: x + 480 − 12x = 150 → −11x = −330 → x = 30, y = 40. Angles: A = 37°, B = 48°, C = 143°, D = 132° ✅ (check: 37+143 = 180, 48+132 = 180 ✓)
⭐Q15. Train: +6 km/h → 6 h less; −4 km/h → 6 h more — distance & speed?
d/s = t; d/(s+6) = t − 6; d/(s−4) = t + 6. From these: d = s(t) and d = (s+6)(t−6) = st − 6s + 6t − 36 → 0 = −6s + 6t − 36 → t = s + 6. Similarly: (s−4)(t+6) = st + 6s − 4t − 24 = st → 6s − 4t = 24 → 3s − 2t = 12. Sub t = s + 6: 3s − 2s − 12 = 12 → s = 24, t = 30. Distance = 720 km ✅ (speed 24 km/h)
⭐Q16. Father = sum of 4 children ages. 20 years later: children sum = 2× father's age — father's age?
F = S (today). After 20 years: each child +20, so children sum = S + 80. Father = F + 20. Given: S + 80 = 2(F + 20). Sub S = F: F + 80 = 2F + 40 → F = 40 years ✅
